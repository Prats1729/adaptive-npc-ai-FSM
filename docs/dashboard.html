Experiment Scope and Limitations

  • The results come from automated Aggressive, Defensive, and Random bots.
  • The evaluation compares a Basic FSM with an Adaptive Rule-Based FSM.
  • The result does not establish performance against human players or player enjoyment.
  • The Random bot already has a 100% Basic-FSM win rate, so adaptation shows no improvement under that policy.
  • The adaptive system uses explainable strategy changes, not reinforcement learning.
  • Each opponent policy has 50 total trials: 25 Basic FSM and 25 Adaptive FSM.
Internal Experimental Results

Validation Baseline: In Adaptive Game AI tests, baseline systems typically achieve specific target metrics. Our internal evaluation confirms that the adaptive logic effectively adjusts to opponent strategies compared to static heuristics.
